## 截图取字 v1.6.0

选中不再"松手即复制"：**选区保持高亮，由底部按钮取走**，方便反复调整后再复制。

### 改动

- 底部按钮行新增 **「复制选中」**，放在「复制全部」左边
- 选区行为改为"提交式"：
  - 轻点词元 → 选中该词（高亮保持）
  - 横向拖过 → 选中一段（高亮保持）
  - 松手不再写入剪贴板，提示行显示"已选 N 字：xxx · 点「复制选中」取走（可继续拖选）"
- 竖向滚动抢走手势时（`ACTION_CANCEL`），**还原上一次已提交的选区**，不会因为想翻页把选区清掉
- 按下词元不再立刻上色，只有真正点击/横拖时才画高亮，避免竖滑时闪一下

### 安装

去 [Releases](https://github.com/Haven-Lv/screenshot-ocr/releases/latest) 下载 `ScreenshotOCR-1.6.0.apk` 覆盖安装。
